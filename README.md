# WebHID 수집·분류

현재 고정 분류·검사기는 [pilot-checker v0.4.0](pilot-checker-v0.4.0/)입니다.

1차 정적 수집은 동료 초기 [km_static](km_static/)을 사용하고, 저장 결과를 v0.4.0으로 분류합니다. 자동 분류는 라벨링 초안이며 최종 C/V·위험 판정을 대신하지 않습니다.

## 이전 버전 보관

- [초기 전달 수집기 v0.1.0](https://github.com/KNU-NGWS-URP/crawl/tree/codex/km-static-v0.1.0-original): 로컬에서 사용 중인 동료 초기 수집기와 코드 내용이 같은 스냅샷.
- [최초 프로토타입](https://github.com/KNU-NGWS-URP/crawl/tree/codex/km-static-initial-6d09b2f): 최초 등록 커밋 6d09b2f의 전체 스냅샷.

v0.4.0 이전 분류기는 로컬에 일부 파일·검증 기록만 남아 있어 완전한 실행 버전으로 별도 등록하지 않았습니다. 기존 수집기 코드는 변경하지 않았습니다.
